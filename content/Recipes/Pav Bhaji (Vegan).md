## Ingredients
| Amount       | Name                       | Prep                                         |
| ------------ | -------------------------- | -------------------------------------------- |
|              | Cauliflower                | Roughly chopped, mod. size                   |
|              | Carrots                    | Roughly chopped, mod. size                   |
|              | Peas                       |                                              |
|              | Potatoes                   | Roughly chopped, mod. size                   |
| 1 medium-big | Red onion                  | Finely chopped                               |
| 2 big        | Tomatoes                   | Finely chopped                               |
| 1            | Green bell pepper          | Finely chopped                               |
| 3-4          | Green chillies             | Finely chopped                               |
| 4-5 cloves   | Garlic                     | Finely chopped                               |
|              | Ginger                     | As much as garlic, finely chopped            |
| 3-4 tsp      | Pav Bhaji masala mix       |                                              |
| 1/2 tsp      | Turmeric (Haldi)           |                                              |
|              | Red chilli powder          | To taste                                     |
|              | Salt                       | To taste                                     |

|              | Bao (buns) or bread slices | Toasted, for serving                         |

## Instructions
**Note:** Use equal ratios of cauliflower, carrots, peas, and potatoes — adjust total quantity to how many you are serving and/or how much fits inside pressure cooker.

1. Add the cauliflower, carrots, peas, and potatoes to a pressure cooker with 1–1.5 coloured cups of water (don't fill to the rim, water level can be quite below the vegetable line, maybe half height?). Cook for 1–2 whistles, then check — vegetables should be soft, ready to be mashed.
2. Once cooked, squish the vegetables with a masher/stamper until you have a rough, chunky mash. Set aside.
3. Meanwhile, in a wok with oil, fry the garlic (4-5 cloves), green chillies (3-4), ginger (same volume as garlic), and red onion (1 medium-big) until softened and lightly golden.
4. Add the tomatoes (2 big) and cook for a few minutes until they break down.
5. Add masala mix (3-4 tsp), salt, turmeric, and red chilli powder. Stir well and let sit on the heat for a couple of minutes for the spices to bloom.
6. Add the green bell pepper and cook until softened, ~5 min.
7. Add the vegetable mash and stir everything together. Cook for a few more minutes until well combined and heated through. Adjust salt to taste.
8. Serve with toasted bao buns or bread slices.
9. (optional) put pieces of cheese slices between layers of Bhaji and let it melt.
