## Ingredients
**Note:** The recipe uses 300g total blueberries (100g for blending, 200g for layering), but you can substitute with any berries such as strawberries, blackberries, raspberries, or a mixture.
### Base
Designed for 22cm oven form. If larger (e.g. 28cm), add 50-100% more of all base ingredients, but filling ingredients below stay the same.
| Amount  | Name          | Prep |
| ------- | ------------- | ---- |
| 30g     | Almonds       |      |
| 40g     | Rolled oats   |      |
| 30g     | Sunflower oil |      |
| 30g     | Dates         |      |

### Filling
| Amount  | Name          | Prep                                                                          |
| ------- | ------------- | ----------------------------------------------------------------------------- |
| 150g    | Cashew nuts   |                                                                               |
| 100g    | Berries       | For blending; e.g., blueberries, strawberries, raspberries, or blackberries   |
| 80g     | Sugar         |                                                                               |
| 200g    | Coconut milk  |                                                                               |
| 200g    | Water         |                                                                               |
| 1.5 tsp | Agar powder   |                                                                               |
| 200g    | Berries       | For layering                                                                  |

## Instructions
1. In the food processor (large bowl, knife blade), pulse the almonds (30g), rolled oats (40g), sunflower oil (30g), and dates (30g) a few times until a medium-grained coarse mix forms. Don't over-process.
2. Press the mixture evenly into a round oven form and bake at 180°C for 15 min.
3. Scrape out the base mixture remnants from the food processor bowl — no need for a full clean. Add cashew nuts (150g), berries (100g), sugar (80g), coconut milk (200g), water (200g), and agar powder (1.5 tsp) to the same bowl and blend until completely smooth.
4. Transfer to a medium pot and heat it until bubbling, stirring constantly, then simmer for a few minutes (sometimes there is a visible color change, e.g., a darkening that signals it's done).
5. Place a layer of berries (200g) on the baked base, then pour the filling over and flatten the surface.
6. Refrigerate for ~4h until fully set before slicing.
