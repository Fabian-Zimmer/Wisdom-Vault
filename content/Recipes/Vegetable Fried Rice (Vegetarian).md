## Ingredients
| Amount         | Name               | Prep                         |
| -------------- | ------------------ | ---------------------------- |
| 400g           | Rice               |                              |
| 1 small        | Cauliflower        | Cut into florets             |
| 2 small/medium | Broccoli           | Cut into florets             |
| 1              | Red bell pepper    | Chopped                      |
| 1              | Yellow bell pepper | Chopped                      |
| 3 medium       | Carrots            | Chopped                      |
| 1 coloured cup | Peas               |                              |
|                | Spring onions      | Whole, then sliced           |
| 5              | Green chillies     | Chopped                      |
|                | Garlic             | Chopped                      |
|                | Ginger             | As much as garlic, chopped   |
| 2 packs        | Paneer             | Cut into small-medium pieces |
| 3 tbsp         | Light soy sauce    |                              |
| 3 tbsp         | Dark soy sauce     |                              |
| 3 tbsp         | Rice wine vinegar  |                              |
| 2 tbsp         | Sesame oil         |                              |
| 2 tbsp         | Sriracha           |                              |
| 1 tbsp         | Crispy chilli oil  |                              |
|                | Neutral oil        | For cooking                  |

## Instructions
**Note:** Use 2 woks. The second wok comes into play only for the final stir-fry stage.

0. Do mis-en-place by pre-chopping all ingredients.
1. Cook rice (400g) first so it has time to cool and dry out — ideally spread on a tray.
2. In one wok, fry garlic, ginger, green chillies, and spring onions (white parts) with a little oil.
3. In separate smaller pot, cook peas.
4. Add cauliflower, broccoli, bell peppers, carrots, and green parts of spring onions into main wok. Cooked until slightly tender.
5. Meanwhile, in the second wok, fry paneer in thick slabs (2-3 can fit in wok) until golden/brown on both sides (flipping as necessary). Set aside in plate or bowl to cool. Once cooled, chop it in cubes.
6. While the vegetables are cooking and paneer is frying, mix the sauce in a bowl: light soy sauce (3 tbsp), dark soy sauce (3 tbsp), rice wine vinegar (3 tbsp), sesame oil (2 tbsp), sriracha (2 tbsp), and crispy chilli oil (1 tbsp).
7. Pour the sauce over the paneer cubes and let them soak in it.
8. Preheat the 2nd wok, and then split the cooked vegetables equally between both woks. Add the dried rice, and the paneer with the sauce equally to both woks as well.
