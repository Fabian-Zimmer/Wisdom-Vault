## Ingredients
| Amount       | Name                   | Prep            |
| ------------ | ---------------------- | --------------- |
| 1 cup        | (Frozen) Edamame       | Thawed          |
| 1 medium-big | Avocado                |                 |
| 1 big        | Garlic clove           |                 |
| 1/2          | Lime                   | Juiced          |
| 15g          | Fresh coriander leaves |                 |
| 1/2 tsp      | Salt                   |                 |
| 2 tbsp       | Olive oil              |                 |
| ~150ml       | Water                  | Adjust to taste |
| 8-10 cracks  | Black pepper           |                 |
| 2 tbsp       | Flax seed powder       |                 |

## Instructions
1. Add all ingredients to a blender: (thawed if frozen) edamame (1 cup), avocado (1), garlic (1 clove), lime juice (1/2 lime), coriander leaves (15g), salt (1/2 tsp), olive oil (2 tbsp), water (~150ml), black pepper (6 cracks), and flax seed powder (2 tbsp).
2. Blend until smooth. Adjust water for a looser consistency or blend less for a chunkier spread. Taste and adjust salt or lime as needed.
3. Store in the fridge.
