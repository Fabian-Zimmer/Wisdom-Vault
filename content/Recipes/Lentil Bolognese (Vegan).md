## Ingredients
| Amount       | Name                  | Prep                         |
| ------------ | --------------------- | ---------------------------- |
| ~185g        | Red lentils           | Soaked in water 30 min.      |
| 720ml        | Vegetable broth       | 1 cube                       |
|              | Olive oil             | For cooking                  |
| 1 large      | Red onion             | Finely chopped               |
| 4            | Garlic cloves         | Thinly sliced                |
| ~35g         | Walnuts               | Finely chopped               |
| 1 tsp        | Dried thyme           |                              |
| 1 tsp        | Dried oregano         |                              |
| 1/4 tsp      | Black pepper          |                              |
| 150g         | Tomato paste          |                              |
| ~100ml       | Red wine              |                              |
| 400ml        | Canned tomatoes       |                              |
| 1 tbsp       | Balsamic vinegar      |                              |
|              | Fresh basil leaves    | Handful, cut                 |
| 350-450g     | Long, wide pasta      | E.g. Mafaldine               |
|              | Salt                  |                              |

## Instructions
1. Soak red lentils (~185g) in water for 30 min. Meanwhile, prepare the vegetable broth (720ml, 1 cube), finely chop the red onion (1 large), thinly slice the garlic (4 cloves), and finely chop the walnuts (~35g).
2. In a wok, sauté the onion with a pinch of salt in olive oil for ~10 min. Add the garlic, thyme (1 tsp), oregano (1 tsp), salt (1 tsp), and pepper (1/4 tsp).
3. Stir in tomato paste (150g) and cook for 2-3 min.
4. Add red wine (~100ml) and cook for 1-2 min. until the alcohol has burned off.
5. Pour in the broth, then add the drained lentils and walnuts. Rapid simmer for ~20 min., stirring occasionally.
6. Meanwhile, cook the pasta (350-450g) in a separate pot of salted water according to package instructions.
7. Add canned tomatoes (400ml) to the wok and simmer for ~15-20 min., stirring frequently.
8. Finish with balsamic vinegar (1 tbsp), stir in the cut basil leaves (handful), and turn off the heat.
9. Add the cooked pasta and stir to combine.
