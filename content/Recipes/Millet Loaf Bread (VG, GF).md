## Ingredients
| Amount           | Name                          | Prep            |
| ---------------- | ----------------------------- | --------------- |
| 300g (2.5 cups)  | Millet flour                  |                 |
| 2.5 tsp          | Baking powder                 |                 |
| 1/2 tsp          | Baking soda                   |                 |
| 2 tbsp           | Ground flax or chia           |                 |
| 3/4 tsp          | Salt                          | Reduce to taste |
| 590ml (2.5 cups) | Water                         |                 |
| 1 tbsp           | Apple cider vinegar           |                 |
| 1/3 cup          | Whole/powdered psyllium husks |                 |
| 2-3 tbsp         | Date syrup                    | Optional        |
|                  | Sesame seeds                  | For topping     |

## Instructions
**Note:** It is difficult to overcook this bread, so if unsure whether it is done, add another 10-15 min. before removing. If the loaf is at all gummy after completely cooling, it wasn't cooked long enough.

1. Preheat oven to 175°C.
2. In a large bowl, combine the dry ingredients: millet flour (300g), baking powder (2.5 tsp), baking soda (1/2 tsp), ground flax or chia (2 tbsp), and salt (3/4 tsp).
3. In a separate bowl, combine the wet ingredients and psyllium husks: water (590ml), apple cider vinegar (1 tbsp), date syrup if using (2-3 tbsp), and whole/powdered psyllium husks (1/3 cup). Leave to rest for ~5 min. until a gel-like consistency forms.
4. Add the wet mixture to the dry ingredients and mix until combined.
5. Wet your hands and transfer the dough into a loaf pan, smoothing the top. Sprinkle sesame seeds evenly across the surface.
6. Bake for 75-80 min. Remove from loaf pan and leave to cool completely (ideally on wire-rack) before slicing — cutting too early will result in a gummy texture.
