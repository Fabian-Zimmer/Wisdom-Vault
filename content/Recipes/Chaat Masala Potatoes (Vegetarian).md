## Ingredients

### Potatoes
| Amount        | Name                  | Prep                                        |
| ------------- | --------------------- | ------------------------------------------- |
| 750g          | Potatoes              | Sliced into ~5-8mm disks along the long axis|
| 1 tsp         | Salt                  | For boiling                                 |
| 2 tbsp        | Olive oil             |                                             |
| 2 tsp         | Chaat masala          | More to taste                               |
| 1/2-1 tsp     | Turmeric powder       |                                             |
|               | Black pepper          | Lots, freshly cracked                       |
|               | Salt                  | To taste                                    |

### Coriander Chutney
| Amount | Name             | Prep                        |
| ------ | ---------------- | --------------------------- |
| 50g    | Coriander leaves | Including majority of stems |
| 1 long | Green chilli     |                             |
| 1 tbsp | Lime juice       |                             |
| 1 tbsp | Water            |                             |
| 50ml   | Olive oil        |                             |
| 1 tbsp | Flaxseed powder  |                             |

### Tamarind Dressing
| Amount        | Name                  | Prep                                        |
| ------------- | --------------------- | ------------------------------------------- |
| 1.5 tbsp      | Tamarind paste        |                                             |
| 1.5 tsp       | Sugar                 |                                             |
| 1/4 tsp       | Chaat masala          |                                             |
| 1.5 tsp       | Water                 |                                             |

### Assembly
| Amount | Name                | Prep                          |
| ------ | ------------------- | ----------------------------- |
| ~140g  | Greek-style yoghurt | ~70g per plate                |
| 1/2    | Red onion           | Thinly sliced into half-rings |

## Instructions

1. Cut potatoes (750g) into ~5-8mm disks along the long axis. Place in a large pot, cover with water by ~4cm, and add salt (1 tsp). Bring to a boil and simmer for ~6 min., until almost cooked through but still retaining a bite. Drain and place on a parchment-lined baking tray. Roughly pat dry.
2. Toss the potatoes with olive oil (2 tbsp), chaat masala (2 tsp), turmeric (1/2-1 tsp), lots of freshly cracked black pepper, and a sprinkle of salt to taste. Roast at 220°C fan for ~35 min. until golden brown.
3. Meanwhile, make the coriander chutney in food processor: blend coriander leaves and stems (50g, only removing the roughest parts if necessary), green chilli (1), lime juice (1 tbsp), water (1 tbsp), olive oil (50ml), and flaxseed powder (1 tbsp) in a food processor until smooth. Set aside.
4. Make the tamarind dressing: whisk together tamarind paste (1.5 tbsp), sugar (1.5 tsp), chaat masala (1/4 tsp), and water (1.5 tsp). Set aside.
5. For each of 2 plates, spread yoghurt (~70g) flat across plate, top with half the coriander chutney swirled through without fully incorporating, drizzle half the tamarind dressing over each, top with half the potatoes, and finish with half of the red onion half-rings scattered across.
