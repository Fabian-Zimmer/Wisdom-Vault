## Ingredients
| Amount     | Name              | Prep                           |
| ---------- | ----------------- | ------------------------------ |
|            | Sunflower oil     | For cooking                    |
| 1 tbsp     | Sesame oil        | For cooking                    |
|            | Garlic            | Lots, chopped                  |
|            | Ginger            | Some, chopped                  |
| 3          | Green chillies    | Finely sliced (for 2 people)   |
|            | Spinach           | Lots                           |
| 3 tbsp     | Peanut butter     |                                |
| 3 tbsp     | Tahini            |                                |
| 3 tbsp     | Chilli oil        |                                |
| 2 tbsp     | Light soy sauce   |                                |
| 1 tbsp     | Rice wine vinegar |                                |
|            | Noodles           | Linguine, ramen, or udon       |
|            | Cucumber          | Julienned                      |
| *Optional* | Firm tofu         | ~250g, dried and cut in strips |

## Instructions
**Note:** Scale chillies and noodles to the number of people serving.

0. *(Optional)* Dry the tofu well and cut into medium-thick slabs. Fry in a pan with a little sunflower oil until golden and crispy on both sides (flip when necessary). Set aside and let cool, then cut in medium-thick strips.
1. Mix the sauce in a bowl: peanut butter (3 tbsp), tahini (3 tbsp), chilli oil (3 tbsp), light soy sauce (2 tbsp), and rice wine vinegar (1 tbsp). Set aside.
2. In a pan with sesame oil, fry garlic and ginger (both generously) and green chillies until fragrant.
3. Meanwhile, cook noodles according to package instructions. Drain and set aside.
4. Add spinach in batches to main pan and cook until wilted.
5. Add the cooked noodles and pour over the sauce. Toss everything together on medium heat until well coated.
6. Serve topped with julienned cucumber and tofu strips if using.
