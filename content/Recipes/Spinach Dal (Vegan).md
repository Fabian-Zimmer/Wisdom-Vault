## Ingredients
| Amount         | Name                   | Prep                     |
| -------------- | ---------------------- | ------------------------ |
| 0.6 cup        | Toor dal               | Washed                   |
| 0.4 cup        | Red lentils            | Washed                   |
| 200g           | Spinach                |                          |
|                | Neutral oil            | For cooking              |
| 1              | Onion                  | Finely chopped           |
| 2              | Green chillies         | Finely chopped           |
|                | Garlic                 | Generous amount, chopped |
|                | Ginger                 | Equal to garlic, chopped |
| 2-3 red spoons | Mustard seeds          |                          |
| 1.5 red spoons | Fenugreek seeds        |                          |
| 1.5 red spoons | Urad dal               |                          |
| 1/2 tsp        | Turmeric               |                          |
| 1/2 tsp        | Jeera powder           | Cumin                    |
| 1/2 tsp        | Coriander powder       |                          |
| 1 tsp          | Red chilli powder      |                          |
| 2-3 dashes     | Hing/Asafoetida powder |                          |
|                | Salt                   | To taste                 |
| *Optional*     | Black pepper           | A crack, for cold days   |
| ~15g           | Fresh coriander leaves | Chopped, to garnish      |

## Instructions
1. Wash the toor dal (0.6 colored cup) and red lentils (0.4 colored cup) thoroughly. Add to the pressure cooker along with spinach (200g), a little salt, and enough water to cover generously.
2. For induction: heat on level 9 for a few minutes until pressure cooker is warm to the touch, then reduce to level 6–7 for 3 whistles, then 1 quick whistle at level 8.
3. Towards the end of pressure cooker steps, make the tarka: in a pan with oil, add mustard seeds, fenugreek seeds, and urad dal. Let them pop.
4. Add onion (1), green chillies (2), garlic, and ginger. Fry until softened and golden.
5. Add turmeric (1/2 tsp), jeera powder (1/2 tsp), coriander powder (1/2 tsp), red chilli powder (1 tsp), and Hing/Asafoetida powder (2-3 dashes). Stir and cook for a minute or two.
6. Add the tarka to the cooked dal. Pour a little water into the tarka pan, scrape out the remaining spices, and add to the dal — the dal will need the extra water anyway.
7. Stir well, adjust water to desired consistency, and season with salt to taste. Add a crack of black pepper if desired.
   {Our preferred consistency is more soupy.}
8. Stir in chopped coriander leaves (~15g).
9. Best served with Roti.
