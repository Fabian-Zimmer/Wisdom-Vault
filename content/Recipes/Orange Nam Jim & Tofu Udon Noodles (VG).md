## Ingredients

### Noodles & Garnish
| Amount  | Name                    | Prep                                    |
| ------- | ----------------------- | --------------------------------------- |
| ~600g   | Pre-cooked udon noodles | About ~300g if using dried udon noodles |
| 10g     | (Thai) basil leaves     |                                         |
| 50g (3) | Spring onions           | Julienned                               |
| 10g     | Coriander leaves        | Finely sliced                           |
| 40g (2) | Red chillies            | Julienned                               |
| 1 tbsp  | Sesame seeds            | White, black, or both; toasted          |
|         | Salt                    |                                         |

### Fried Tofu
| Amount   | Name          | Prep                                                   |
| -------- | ------------- | ------------------------------------------------------ |
| 350g     | Firm tofu     | Pressed, patted very dry, cut into small-medium pieces |
| 1 small  | Garlic clove  | Crushed                                                |
| 2 tbsp   | Soy sauce     |                                                        |
| 1/2 tbsp | Maple syrup   |                                                        |
| 1/4 tsp  | Salt          |                                                        |
|          | Sunflower oil | For frying                                             |

### Blood Orange Nam Jim
| Amount          | Name                          | Prep                                                 |
| --------------- | ----------------------------- | ---------------------------------------------------- |
| 1/2 tsp         | Chilli flakes                 |                                                      |
| 160ml           | Blood or regular orange juice | From 4-5 oranges; remainder cut into wedges to serve |
| 20g             | Tamarind paste                | Shop-bought; or double if extracting from pulp       |
| 4 tbsp          | Light soy sauce               |                                                      |
| 1/2 tbsp        | Maple syrup                   |                                                      |
| 40g (1/2 small) | Onion                         | Banana shallot, red or white onion; finely diced     |
| 5g              | Coriander                     | Finely chopped                                       |

## Instructions
**Note:** The nam jim can be made ahead and kept in a jar in the fridge for up to a week — consider doubling it. Noodles are best served at room temperature, having soaked up the sauce; tofu is best hot and freshly fried. If using dried noodles, cook according to package instructions and drain well before tossing with the sauce.

0. If using dried udon noodles, cook to package instructions.
1. Heat sunflower oil in a wok or large non-stick pan over medium-high heat. Add the tofu pieces along with the crushed garlic (1 clove), soy sauce (2 tbsp), maple syrup (1/2 tbsp), and salt (1/4 tsp). Fry for a few minutes, tossing and turning frequently, ideally until crisp and golden-brown.
2. Meanwhile make the nam jim: combine orange juice (160ml), tamarind paste (20g), soy sauce (4 tbsp), maple syrup (1/2 tbsp), chilli flakes (1/2 tsp), onion (40g), and coriander (5g) in a bowl. Mix well, then add all to the tofu and cook for 2 min. until warm. 
3. Add the noodles (~600g). Cook for another 3 min., stirring to separate the noodle strands.
4. Toss the basil (10g), spring onions (50g), coriander leaves (10g), and chillies (40g) through the noodles. Transfer to a serving platter. Finish with toasted sesame seeds (1 tbsp). Serve with orange wedges alongside if leftovers.
