## Ingredients

### Sponge Cake Base

| Amount   | Name               | Prep         |
| -------- | ------------------ | ------------ |
| 100g     | Whole pastry flour |              |
| 20g      | Almonds            |              |
| 30g      | Neutral oil        |              |
| 50g      | Cane sugar         |              |
| 100g     | Soy milk           |              |
| 2 tsp    | Matcha powder      |              |
| 1 tsp    | Baking powder      |              |

### Berry-Cashew Filling

| Amount | Name         | Prep                                                            |
| ------ | ------------ | --------------------------------------------------------------- |
| 105g   | Cashew nuts  |                                                                 |
| 70g    | Berries      | For blending; strawberries or blueberries pair well with matcha |
| 55g    | Sugar        |                                                                 |
| 140g   | Coconut milk |                                                                 |
| 140g   | Water        |                                                                 |
| 1 tsp  | Agar powder  |                                                                 |

## Instructions
**Notes:** 
- Can use square oven form (6''x6'') or round oven form (22cm)
- The filling sets firm as it cools — work quickly when pouring it over the sponge.

1. Preheat oven to 170°C. 
2. Pulse the almonds (20g) in the food processor (small bowl and knife blade) to a fine meal. Then transfer to a mixing bowl.
3. To the mixing bowl, add pastry flour (100g), matcha (2 tsp), baking powder (1 tsp), sugar (50g), oil (30g), and soy milk (100g) and mix well by hand.
4. Pour into a parchment-lined oven form (see notes above) and bake for 20-25 min. until a toothpick comes out clean. Leave to cool completely in the pan.
5. Make the filling in the food processor (big bowl and knife): blend cashews (105g), berries (70g), sugar (55g), coconut milk (140g), and water (140g) until completely smooth.
6. Transfer to a medium pot and whisk in agar powder (1 tsp). Heat it up until bubbling, stirring constantly, then simmer for a few minutes (sometimes there is a visible color change, e.g., a darkening that signals it's done).
7. Pour the hot filling evenly over the cooled sponge in the form. Leave to cool to room temperature, then refrigerate until fully set, ideally a few hours, before slicing.
